# AI_Writer_TISTORY Service Roadmap

## 서비스 목표

AI가 만든 초안을 운영자가 검수하고 발행 준비를 끝낼 수 있는 백엔드 파이프라인으로 정리합니다.

## Priority 1

- 초안 생성과 실제 발행 사이에 승인 단계를 둡니다.
- 제목, 설명, 링크, 중복 문장을 검사하는 SEO 검수 로직을 추가합니다.
- 티스토리 API 실패 기록을 운영자가 읽기 쉬운 로그로 정리합니다.

## Priority 2

- 프롬프트 버전별 산출물 비교를 지원합니다.
- 블로그별 톤과 금지 규칙을 UI나 설정 파일로 관리합니다.
- 예약 발행 전 체크리스트를 자동으로 보여줍니다.

## Ops

- rate limit과 실패 재시도 정책을 문서화합니다.
- 발행 전 사람이 최종 확인해야 하는 기준을 남깁니다.
